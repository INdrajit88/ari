# PasteMe Lite (macOS Clipboard Manager)

This repository now includes a lightweight macOS clipboard manager app inspired by tools like PasteMe.

## Project location

- `PasteMeLite/` — Swift Package containing the macOS app.

## Features

- Automatic clipboard history capture for text.
- Search across clipboard history.
- Pin important snippets.
- Copy previous snippets back to the clipboard.
- Clear only unpinned history.

## Run locally (on macOS)

1. Open Terminal on macOS.
2. Navigate to the project:
   ```bash
   cd PasteMeLite
   ```
3. Build and run:
   ```bash
   swift run
   ```

> You can also open the package in Xcode (`File > Open...`) and run it as a macOS app.
